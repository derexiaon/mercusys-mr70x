# OpenWrt 25.12 + Xray + pbr + AmneziaWG для Mercusys MR70X v1

Прошивка **OpenWrt 25.12.5** для **Mercusys MR70X v1** (MT7621, 16 МБ флеш, 128 МБ ОЗУ),
собранная из исходников и ужатая под маленькую флешку. Внутри:

- **Xray-core 26.3.27** (облегчённая сборка) — клиент **VLESS** (REALITY / TLS,
  XTLS Vision, XHTTP, WebSocket, HTTPUpgrade), **Hysteria2** (salamander, port hopping),
  **Trojan**, **Shadowsocks** (включая SS-2022);
- **подписки на VPN**: вставляете URL подписки из панели (3x-ui, Marzban, Remnawave…),
  роутер сам скачивает список серверов и обновляет его каждый день;
- **автовыбор сервера**: при нескольких серверах Xray раз в 2 минуты проверяет их и
  использует самый быстрый живой — если сервер упал, трафик сам переходит на другой;
- **AmneziaWG** (модуль ядра + LuCI) — если провайдер VPN даёт AWG-конфиг;
- **pbr** + **luci-app-pbr** — в VPN идут только нужные сайты, по спискам
  [itdoginfo/allow-domains](https://github.com/itdoginfo/allow-domains)
  («Russia inside» + подсети Telegram, Meta, Twitter, Discord), обновляются каждый день;
- PPPoE, Wi-Fi 6 (MT7915), LuCI на русском, часовой пояс MSK.

В туннель уходит **только** трафик к ресурсам из списков, остальное идёт напрямую
через провайдера (как в AntiZapret).

> **Статус.** Сборка, размер образа и работа скриптов (разбор ссылок и подписок,
> генерация и проверка конфигов Xray, первичная настройка) автоматически
> проверяются в CI в qemu-chroot собранной системы. На живом MR70X прошивка пока
> не проверялась — держите под рукой аварийное восстановление (см. ниже) и
> сообщайте о проблемах в Issues.

## Почему именно так

Флеш у MR70X — 16 МБ, из них под прошивку 15,4 МБ; USB нет, так что расширить место
нельзя. Полный Xray для MIPS весит 34 МБ (6,8 МБ в сжатом виде), обычный образ
OpenWrt с LuCI и pbr — 9,2 МБ. Чтобы всё поместилось и осталось место под настройки:

| Решение | Что даёт |
| --- | --- |
| Xray собирается из исходников с урезанным набором модулей (`xray-slim/`) | убраны gRPC, WireGuard, VMess, API/статистика, TOML/YAML; остались VLESS, Hysteria2, Trojan, Shadowsocks, TUN — 5,7 МБ вместо 6,8 МБ |
| Прошивка собирается из исходников, а не ImageBuilder'ом (`openwrt/diffconfig`) | блоки squashfs 1 МБ вместо 256 КБ (лучше сжатие), ядро без отладочных функций (kallsyms, debugfs, ftrace, perf…), mklibs вырезает неиспользуемые функции из библиотек |
| Нет пакетного менеджера `apk` и IPv6-сервисов (odhcpd, odhcp6c) | ставить пакеты всё равно некуда; туннели работают по IPv4, а IPv6 позволил бы обходить туннель — ответы AAAA тоже отфильтрованы |
| Нет `geoip.dat` / `geosite.dat` | они весят мегабайты; маршрутизацию по доменам делает pbr + dnsmasq nftset |
| Списки и подписка хранятся/скачиваются в ОЗУ, во флеш пишется только результат | флеш не изнашивается |
| `GOMEMLIMIT=40MiB`, `GOGC=50` | Xray не съедает всю память роутера |

Точные размеры Xray, образа и свободного места под настройки — в сводке каждой
сборки в Actions.

## Как это работает

```
Клиент LAN ──► dnsmasq ──(DNS)──► 127.0.0.1:5353 ─► Xray ─► VPN-сервер ─► 1.1.1.1
     │            │
     │            └─ домены из списков → nft set pbr
     │
     └──► pbr: адрес в списке? ──да──► xray0 (TUN) ─► Xray ─► лучший из серверов
                              │                              (VLESS/Hysteria2/Trojan/SS)
                              ├─да (если выбран AWG)──► awg0 (AmneziaWG)
                              └─нет──► wan (напрямую)
```

Интерфейс `xray` (устройство `xray0`, адрес 172.19.0.1/30), зоны firewall `xray` и `awg`
создаются при первой загрузке. Соединения с самими VPN-серверами всегда идут мимо
туннеля (политика `Xray server (direct)`, заполняется автоматически).

## Где взять прошивку

- **Releases** — готовые сборки;
- **Actions → build → последний успешный запуск → Artifacts** — сборка любого коммита.

Файлы:

- `…-mercusys_mr70x-v1-squashfs-factory.bin` — для прошивки из заводского веб-интерфейса;
- `…-mercusys_mr70x-v1-squashfs-sysupgrade.bin` — для обновления из OpenWrt.

## Установка

**С заводской прошивки Mercusys**

1. Веб-интерфейс роутера → *Система / System Tools → Обновление ПО / Firmware Upgrade* →
   загрузить `factory.bin`.
2. После перезагрузки роутер доступен на `http://192.168.1.1` (логин `root`, без пароля) —
   сразу задайте пароль.

**С OpenWrt**

LuCI → *Система → Резервная копия / прошивка → Установить новую прошивку* → `sysupgrade.bin`.
При переходе с другой сборки (в том числе с первых версий этой) **не сохраняйте настройки**:
первичная настройка сети, firewall и pbr выполняется только на чистой системе.

**Восстановление** (если что-то пошло не так): выключить роутер, зажать Reset,
включить и держать 5–10 секунд, вручную задать компьютеру IP `192.168.1.2/24`
и открыть `http://192.168.1.1` — это аварийный веб-интерфейс загрузчика, через него
можно залить `factory.bin` OpenWrt или заводскую прошивку.

## Настройка

1. Настройте интернет: *Сеть → Интерфейсы → WAN* (для PPPoE — протокол PPPoE,
   логин и пароль провайдера) и Wi-Fi.
2. *Службы → Xray*:
   - **Подписка** — URL подписки из панели VPN, и/или
   - **Ссылки** — свои серверы, по одной на строку: `vless://`, `hysteria2://` (`hy2://`),
     `trojan://`, `ss://`;
   - **Сервер** — «Автоматически» (самый быстрый живой) или конкретный сервер;
   - «Сохранить и применить». Внизу появится список серверов, а неподдерживаемые
     ссылки будут перечислены с причиной.
3. Через минуту проверьте, что открываются заблокированные сайты.

То же самое из консоли:

```sh
xray-link --sub 'https://panel.example.com/sub/...'   # подписка
xray-link 'vless://...' 'hy2://...'                   # свои ссылки
xray-link --update                                    # обновить подписку сейчас
xray-link --show                                      # что настроено
```

### AmneziaWG

1. *Сеть → Интерфейсы → Добавить интерфейс*: имя **`awg0`**, протокол **AmneziaWG**.
   Конфиг от провайдера можно загрузить кнопкой импорта. Галочку «Route Allowed IPs»
   **не ставьте** — маршрутизацией занимается pbr.
2. Зона firewall `awg` и поддержка интерфейса в pbr для `awg0` уже настроены.
3. В *Службы → Маршрутизация по политикам* выберите в нужных политиках интерфейс
   `awg0` вместо `xray` (или сделайте копию политики для `awg0`).

### Какие сайты идут через VPN

*Службы → Маршрутизация по политикам (pbr)*. Предустановлены политики:

| Политика | Что делает |
| --- | --- |
| `Xray server (direct)` | соединения с самими VPN-серверами всегда идут напрямую (заполняется автоматически) |
| `Russia inside: domains` | [список доменов itdoginfo](https://github.com/itdoginfo/allow-domains) — YouTube, Instagram, Discord, ChatGPT и т.д. |
| `Telegram, Meta, Twitter, Discord subnets` | подсети этих сервисов (для приложений, которые ходят по IP) |
| `My domains` | ваш собственный список доменов через пробел — добавляйте сюда что нужно |

В политике можно указывать домены, IP, подсети и ссылки на списки (`https://...`).
Можно также ограничить политику отдельными устройствами (поле «Локальные адреса»),
например чтобы телевизор ходил через VPN целиком.

Каждый день в 05:20 обновляется подписка, в 05:30 — списки сайтов. Вручную — кнопками
«Обновить подписку» и «Обновить списки сайтов» на странице Xray.

### Если VPN-сервер недоступен

При нескольких серверах Xray сам переключится на живой. Если не работает ни один —
весь DNS идёт через туннель, поэтому «пропадёт интернет». Нажмите **Остановить** на
странице *Службы → Xray* — DNS сразу вернётся на провайдера.
Отключить DNS через туннель насовсем: `uci set xray.main.dns_tunnel=0; uci commit xray; /etc/init.d/xray restart`.

### Настройки `/etc/config/xray`

| Опция | По умолчанию | Описание |
| --- | --- | --- |
| `enabled` | `1` | запускать Xray |
| `subscription` | — | URL подписки |
| `server` | `auto` | `auto` или имя сервера из списка |
| `max_servers` | `10` | сколько серверов брать из подписки (каждый проверяется раз в 2 минуты) |
| `sub_user_agent` | `v2rayN/7.0` | User-Agent при скачивании подписки (панели отдают по нему формат) |
| `config` | `/etc/xray/config.json` | конфиг Xray (генерируется `xray-link`, можно писать руками) |
| `dns_tunnel` | `1` | весь DNS роутера через туннель |
| `dns_port` | `5353` | локальный порт DNS-форвардера Xray |
| `upstream_dns` | `1.1.1.1` | DNS-сервер на той стороне туннеля |
| `bootstrap_dns` | `77.88.8.8` | DNS для имён VPN-серверов, подписки и NTP (в обход туннеля) |
| `memlimit` | `40MiB` | мягкий лимит памяти Go |

После изменения опций выполните `xray-link --apply`. Конфиг, ссылки и подписка
(`/etc/xray/`) сохраняются при sysupgrade.

### Диагностика

```sh
logread -e xray                  # лог Xray
xray-link --show                 # ссылки, подписка, серверы
/etc/init.d/pbr status           # что делает pbr
nft list sets inet fw4 | grep pbr   # nft set'ы, которые заполняет pbr
ip route show table all | grep -e xray0 -e awg0
```

Не запускайте `xray run -test` на рабочем конфиге при запущенном Xray: тест
действительно открывает устройство `xray0`. `xray-link` проверяет копию конфига без TUN.

## Ограничения облегчённого Xray

Поддерживается: VLESS (+ flow `xtls-rprx-vision`, + VLESS Encryption), Trojan,
Shadowsocks (AEAD и 2022), Hysteria2; транспорты RAW/TCP, XHTTP, WebSocket,
HTTPUpgrade; REALITY/TLS; inbound TUN, dokodemo-door, SOCKS, HTTP.

Не поддерживается (такие ссылки пропускаются с объяснением): VMess, WireGuard внутри
Xray (для этого есть AmneziaWG), gRPC и mKCP, плагины Shadowsocks, `geoip:` / `geosite:`.

Xray 26 больше не позволяет отключать проверку сертификата (`insecure=1`):
для самоподписанных сертификатов в ссылке нужен хеш — `pinSHA256=` (Hysteria2) или `pcs=`.

## Сборка самостоятельно

Всё собирается в GitHub Actions (`.github/workflows/build.yml`), примерно 1,5–2 часа:

1. Xray-core клонируется по тегу и собирается скриптом `xray-slim/build.sh`
   (`GOARCH=mipsle GOMIPS=softfloat`, `-trimpath -s -w`).
2. OpenWrt клонируется по тегу, подключается фид [awg-openwrt](https://github.com/Slava-Shchipunov/awg-openwrt)
   (`openwrt/feeds.conf.extra`), применяется `openwrt/diffconfig`, `make`.
3. Проверяется размер и запускается `tests/smoke.sh`: в собранной системе под qemu
   проверяются первичная настройка, разбор ссылок всех протоколов и подписки,
   автовыбор сервера, отбраковка серверов, которые не принимает Xray.

Сменить версии можно при ручном запуске (*Actions → build → Run workflow*), там же —
выпустить релиз (поле `release_tag`, например `v25.12.5-3`).

Структура:

```
openwrt/diffconfig                 конфигурация сборки OpenWrt
openwrt/feeds.conf.extra           дополнительные фиды (AmneziaWG)
xray-slim/                         урезанная сборка Xray (список модулей + заглушки)
files/etc/init.d/xray              procd-сервис, DNS через туннель
files/usr/bin/xray-link            ссылки/подписка → /etc/xray/config.json
files/usr/share/xray-link/gen.uc   разбор ссылок и генерация конфига (ucode)
files/etc/uci-defaults/99-mr70x-xray  первичная настройка сети, firewall, pbr
files/www/.../view/xray-link.js    страница LuCI
tests/smoke.sh                     проверка в qemu-chroot
```
